# TELOS · Versiones oficiales

Canal público de instaladores Android, números de versión y notas de cambios. El código fuente y las claves de firma se mantienen en privado.

- [Descargar la última versión y leer sus cambios](https://github.com/RudyIndustries/TELOS-updates/releases/latest)
- [Historial de versiones](https://github.com/RudyIndustries/TELOS-updates/releases)
- [Notas de cambios](CHANGELOG.md)

Android 8 o posterior, ARM64. Instala el APK encima de TELOS para conservar favoritos, playlists, recientes y ajustes. No desinstales la versión anterior. Android puede pedirte autorizar la fuente y confirmar la actualización.

A partir de 0.5.2, TELOS permite consultar nuevas versiones desde Ajustes → Actualizaciones de TELOS, leer sus cambios y descargar el APK. Los instaladores incluyen su suma SHA-256. Las versiones anteriores necesitan una primera actualización manual para incorporar esta función.

La música permanece local. No se publican canciones, historiales, claves de firma ni credenciales en este repositorio.
